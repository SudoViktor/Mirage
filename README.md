# Mirage
<img width="1191" height="823" alt="Знімок екрана 2026-11-26 о 09 16 47" src="https://github.com/user-attachments/assets/feb7362d-5eaf-4311-b637-34a479730cef" />

**Mirage** — це утиліта для macOS, яка монтує хмарне сховище Telegram як звичайний диск прямо у **Finder** через **Telegram User API** (TDLib / MTProto). Замість ручного завантаження та вивантаження файлів через клієнт месенджера можна працювати з ними як зі звичайним томом: відкривати, копіювати, переміщувати, видаляти та відновлювати бекапи бази.

---

## Що вміє Mirage

* **Інтеграція з Finder:** сховища з'являються як диски в macOS Finder зі звичайними файловими операціями (drag-and-drop, копіювання, переміщення, видалення).
* **Робота через Telegram User API:** підключається до акаунту через User API, щоб не впиратися в обмеження Bot API.
* **Керування сховищами та чергою:** створення сховищ, моніторинг відвантажень і завантажень у вкладці черги, очищення локального кешу та кешу TDLib.
* **Бекапи та відновлення:** резервне копіювання локальної бази стану сховища у Telegram та відновлення обраної версії.
* **Локальне зберігання ключів:** `api_id` та `api_hash` не зашиті в коді й зберігаються локально на пристрої через `UserDefaults`.

---

## Що таке `api_id` та `api_hash` і навіщо вони потрібні

**`api_id`** (числовий ідентифікатор) та **`api_hash`** (секретний ключ-хеш) — це ключі застосунку для доступу до Telegram API через MTProto/TDLib.

* **Навіщо вони потрібні:** Telegram видає їх розробникам, щоб ідентифікувати клієнтський застосунок при підключенні до серверів Telegram і закріплювати ліміти запитів за конкретним застосунком, а не за одним спільним ключем.
* **Чому вони не зашиті в репозиторії:** у публічному коді чи спільному бінарнику вбудовані ключі легко витягнути, а загальний трафік через один ключ може призвести до обмежень або блокування застосунку з боку Telegram. Тому кожен користувач вказує власні ключі, і вони зберігаються локально на його Mac.

## Як отримати та вставити `api_id` і `api_hash`

### 1. Отримання ключів на `my.telegram.org`
1. Перейдіть на https://my.telegram.org та увійдіть у свій обліковий запис Telegram.
2. Відкрийте розділ **API development tools**.
3. Якщо застосунок ще не створено, заповніть форму (назва та коротка назва — довільні, платформу можна вказати `Desktop` або `Other`) і створіть його.
4. Скопіюйте значення **`App api_id`** (число) та **`App api_hash`** (рядок символів).

### 2. Вставка ключів у Mirage
1. Запустіть **Mirage** на macOS.
2. На стартовому екрані натисніть **«Почати використання»** (якщо ключів ще немає, з'явиться системне вікно запиту `api_id` та `api_hash`).
3. Введіть **`api_id`** та **`api_hash`** у відповідні поля та натисніть **«Зберегти»**.
4. Якщо потрібно замінити старі ключі на нові, на стартовому екрані у правому верхньому куті натисніть сіру кнопку **«Змінити ключі»**, оновіть значення та збережіть їх.

Логіку роботи, взаємодію з Telegram User API та принципи поведінки файлової системи спроєктовано самостійно, а технічну реалізацію на Swift зібрано за допомогою Gemini без глибокого попереднього досвіду у Swift.
